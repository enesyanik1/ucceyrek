ÜÇÇEYREK - İLK SÜRÜM

Cloudflare Pages projesi olarak dağıtılacak kaynak dosyaları.

ÖNEMLİ: functions/api/*.js dosyaları Cloudflare Pages Functions içerir. Cloudflare Pages'te Git entegrasyonu üzerinden dağıtım yapın (GitHub repo köküne bu dosyaları koyun; build komutu boş, output dizini / veya .). Cloudflare Pages'in basit sürükle-bırak statik dosya yüklemesi Functions kodlarını çalıştırmaz.

Yerelde statik HTML açıldığında API uçları çalışmaz; Cloudflare Pages üzerinde test edin.

Piyasa API: USD/TRY, EUR/TRY, GBP/TRY için open.er-api.com, ons altın için gold-api.com. Gram altın hesaplanan REFERANS değerdir. Alış/satış, çeyrek, yarım, tam altın, değişim yüzdesi ve grafikler henüz aktif DEĞİLDİR; bu alanlarda uydurma değer gösterilmez. Kaynakların kullanım şartları ve ticari lisansları yayın öncesinde doğrulanmalıdır.

Haberler Google News RSS arama sonuçlarının başlık ve kaynak bağlantılarından oluşur; haberler sitenizde yeniden yayınlanmaz. RSS erişimi/uygunluğu değişebilir. Kaynak kullanım koşullarını kontrol edin.

Bu bir ilk sürümdür. Gerçek alış-satış verileri için lisanslı fiyat sağlayıcısı entegrasyonu gereklidir.
